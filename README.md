# おつかい探検隊

5歳ごろの子ども向けの、町を育てながら遊ぶブラウザ学習アプリです。数、ひらがな、形、大小比較、迷路を収録しています。

## 遊び方

1. どうぶつから音声で問題を聞きます。
2. 商品や答えをタップします。迷路では矢印で移動します。
3. 正解するたびに建物や住人が町へ増えます。
4. 9つのおつかいを完了すると町が完成し、メダルを獲得できます。

文字は端末の日本語音声で読み上げます。外部ライブラリ、広告、通信、個人情報の収集はありません。

## GitHub Pagesで公開する

このフォルダの中身をGitHubリポジトリへ置き、リポジトリの **Settings → Pages** で公開元を設定します。

- このフォルダをリポジトリ直下にする場合：`Deploy from a branch` → `main` / `(root)`
- 親フォルダごと公開する場合：公開URLの末尾に `/おつかい探検隊/` を付けます。ただしURL互換性のため、フォルダ名を `otsukai-tankentai` に変更する方法がおすすめです。

ローカル確認では `index.html` を直接開けます。オフライン対応（Service Worker）は、GitHub PagesまたはローカルWebサーバー上で有効になります。

## 初版で仮決めした仕様

- 対象：5歳前後、ひらがなが完全には読めなくても遊べる
- 学習範囲：1〜5の数、ひらがなの語頭音、丸・三角・四角、多少比較、4×4迷路
- 1プレイ：全9問、約5〜8分
- 失敗時：不正解表示ではなく「あと○こ」「○こ戻そう」というヒント
- データ：最高到達数のみ端末内に保存
- 収益化、アカウント、ランキング：なし
